# Nayan Patidar — Portfolio

Personal portfolio site for Nayan Patidar (CS @ IIT Jodhpur).

**Concept:** Foundation → Ascent — a single-scroll climb from bedrock values to shipped work.

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Framer Motion (elevation rail)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Deploy

Import the repo at [vercel.com/new](https://vercel.com/new), or:

```bash
npx vercel --prod
```
